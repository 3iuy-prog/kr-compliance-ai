# A. 데이터 수집 갭 분석 (Data Sources)

법률 AI가 다룰 문서를 **3계층**으로 분류하고, 각 계층의 수집 경로·형식·갭을 정리한다.
핵심 결론: **법령·행정규칙(고시)까지는 API로 자동 수집이 되고, 진짜 수집 갭은 "인증기준/점검 체크리스트"뿐이다.**

---

## 계층 구조 한눈에

| 계층 | 예시 문서 | 수집 경로 | 자동화 | 상태 |
|---|---|---|---|---|
| **L1 법령** | 전자금융거래법·정보통신망법·신용정보법·개인정보보호법·위치정보법 + 시행령/시행규칙 | legalize-kr / 법령 OpenAPI | ✅ 완전 | 확보 |
| **L2 행정규칙(고시·훈령)** | 개인정보 안전성확보조치 기준, 전자금융감독규정+시행세칙, 주요정보통신기반시설 취약점 분석·평가 기준 | law.go.kr 행정규칙 API (`admRul`) | ✅ API 있음 | 확보 가능 |
| **L3 인증기준·점검 체크리스트** | ISMS-P 인증기준(101개), 전자금융기반시설 취약점 분석·평가 기준(점검항목), ISO27001 | KISA/FSEC 별도 PDF·HWP | ❌ 수동 | **갭** |

---

## L1 — 법령 (확보됨)

- legalize-kr이 국가법령정보센터 OpenAPI 기반으로 전체 법률/시행령/시행규칙을 Markdown+Git으로 제공.
- 대상 5개 법 전부 커버: 전자금융거래법·정보통신망법·신용정보법·개인정보보호법·위치정보법 및 하위 시행령/시행규칙.

## L2 — 행정규칙 (API로 확보 가능)

처음 우려와 달리 **주요 고시들이 대부분 국가법령정보센터의 "행정규칙"으로 등재**되어 있어 법령 MCP의 행정규칙(`admRul`) 도구로 접근 가능하다.

- **개인정보의 안전성 확보조치 기준** — 개인정보보호위원회 고시. **현행 제2026-9호(2026. 7. 1. 일부개정, 발령한 날부터 시행. 단 제15조제5호·제18조는 2027-01-01 시행)** — 안내서 2026.11판 부칙·제개정 이력으로 확인(2026-11-11). 직전 개정은 '25.10. 행정규칙으로 등재, 별표 포함. 신구법 비교/다운로드 제공.
  - 해설서: 「개인정보의 안전성 확보조치 기준 안내서」 2026.11판(개인정보위 안내서 게시판 '현재 안내서', 2026-11-05 게시). 이력: '24.10 통합본 → '25.11 개정 → '26.11 개정.
  - `law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000192069`
- **전자금융감독규정 / 전자금융감독규정시행세칙** — 금융위·금감원 행정규칙. 본문+부칙+별표/서식(보안성심의신청서, IT부문 실태평가 항목 등) 포함.
  - `law.go.kr/LSW/admRulInfoP.do?admRulSeq=2000000077643`
- **주요정보통신기반시설 취약점 분석·평가 기준** — 행정규칙으로 등재.

> ⚠️ 주의: 행정규칙은 개정 주기가 짧고 별표/서식이 본문과 분리되어 있어, MCP로 조회 시 **별표까지 함께 수집**하는 로직이 필요.

## L3 — 인증기준·점검 체크리스트 (수동 수집 = 진짜 갭)

법령·행정규칙이 **아니므로** law.go.kr에 없다. 별도 기관 자료실에서 PDF/HWP를 받아 파싱·정형화해야 한다. **여기가 프로젝트 성패를 가르는 지점.**

### ISMS-P 인증기준
- 근거: 「정보보호 및 개인정보보호 관리체계 인증 등에 관한 고시」(제2024-8호, 2024-07-24 시행) 별표 7.
- 구성: **101개** = 관리체계 수립·운영(16) + 보호대책 요구사항(64) + 개인정보 처리단계별 요구사항(21).
- 안내서: 「ISMS-P 인증기준 안내서」 2023.11판(KISA 자료실 2023-11-23 수정 게시)이 2026-11-12에 확인한 최신판이다.
- 제도 변화: 개인정보보호법 제32조의2 제1항 단서(2026-03-10 개정)로 대통령령이 정하는 기준에 해당하는 개인정보처리자는 인증을 받아야 한다. 이 단서는 부칙 제1조에 따라 **2027-07-01부터 시행**된다(법률 본문은 2026-09-11 시행). 대상 기준은 시행령으로 정하며 아직 확인하지 않았다. 2026년 4월 과기정통부·개인정보위가 인증제 개편 방안(강화·표준·간편 등급 등)을 발표했고, 안내서 개정판은 아직 나오지 않았다. 개정판이 나오면 다시 수집한다.
- 출처: KISA ISMS-P 누리집 자료실 `isms-p.or.kr` / `isms.kisa.or.kr`.
- 형식: 인증기준 안내서 PDF(항목별 "인증기준 / 주요 확인사항 / 결함사례" 구조) → **표 파싱 필요**.

### 전자금융기반시설 취약점 분석·평가 기준
- 규모: 2026년 기준 **15개 분야 869개 점검항목** + 클라우드 특화 73개(2025년 14분야 789개에서 확대).
- 구성: 관리적·물리적·기술적 보안. 서버 부문만 120~130여 항목.
- 출처: 금융보안원 `fsec.or.kr` 취약점 분석·평가 자료.

### ISO/IEC 27001
- 국제표준(유료). 부속서 A 통제항목(2022판 93개) 기준.
- 원문 재배포 불가 → **통제항목 번호·명칭 수준의 매핑 테이블**만 자체 작성 권장.

---

## 수집 전략 요약

1. **L1+L2는 MCP/legalize-kr로 실시간 조회** — 원문 저장 부담 없음, 인용 근거 자동 확보.
2. **L3만 사전 수집·정형화** — PDF/HWP → 구조화 JSON(항목ID·항목명·확인사항·근거법령). 이게 이 프로젝트의 **자체 데이터 자산**.
3. **L3 ↔ L1/L2 매핑 테이블 구축** — "ISMS-P 2.6.1 ↔ 안전성확보조치 제5조 ↔ 개인정보보호법 제29조" 식 크로스레퍼런스. (B단계 핵심 기능의 데이터 기반)
